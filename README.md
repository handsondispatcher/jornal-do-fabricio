# Jornal do Fabricio

Edição pública: https://handsondispatcher.github.io/jornal-do-fabricio/

O workflow `Atualizar Jornal` coleta notícias e gera `index.html`. A agenda do GitHub Actions é solicitada a cada 30 minutos, sem garantia de pontualidade. A página aberta verifica nova versão a cada minuto. RSS e agregadores não garantem imagens, cobertura completa ou verificação editorial.

Para a primeira publicação: aba **Actions** > **Atualizar Jornal** > **Run workflow**. O workflow precisa ter permissão para gravar conteúdo no repositório em Settings > Actions > General > Workflow permissions > Read and write permissions. GitHub Pages: Settings > Pages > Deploy from a branch > main / (root).
